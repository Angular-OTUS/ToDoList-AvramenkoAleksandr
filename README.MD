# TODO list

Simple TODO list application using Angular

## Requirements

1. NodeJS + NPM
2. json-server (global installation):
`npm install -g json-server`

## Running in development

To run Angular front and fake API back server one should use command:
`npm run dev`
Angular app will be accessible by URL <http://localhost:4200>
Fake API back will be accessible by URL <http://localhost:3000>
